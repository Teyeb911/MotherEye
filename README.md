# MotherEye

AI-powered child protection platform

## Folders

- **backend/** - Backend code goes here
- **mobile_app/** - Mobile app goes here
- **design/** - Design assets go here
- **docs/** - Documentation goes here

## For Teyeb (Designer)

When you finish your designs:
1. Save all mockups, colors, icons, typography
2. Upload to: `design/` folder
3. Create `design/README.md` with your design guide
4. Push to GitHub

## Getting Started

1. Clone this repo
2. Work in your folder
3. Push regularly to GitHub
